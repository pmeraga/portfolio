# Data provenance and public packaging

Source: Shirvalkar et al., *Data and code from: Personalized closed-loop deep brain stimulation for chronic pain: A randomized, double-blind crossover pilot trial*. [Dryad](https://datadryad.org/dataset/doi:10.5061/dryad.b2rbnzsvr), DOI 10.5061/dryad.b2rbnzsvr. Published October 27, 2026. The dataset metadata and archived README state a **CC0 1.0** data release. Authors and source are credited without implying endorsement.

Source archive: `Shirvalkar_sEEGCLDBS_2026.zip`, Dryad file 5028138.

- Bytes: 24,850,190
- SHA-256: `a149ffb68f39a61566374af54bd35cea2c47e2b67c2e0c35307271f3b0542729`

The reference reads nine original `neural_data/ambulatory_stages123/*_ambulatory_features.h5` files and `data/extended_figures_raw_pain/longitudinal_phase_metadata.csv`. These are ten functional source files, representing five participants and overlapping bilateral observations. None was generated by splitting an existing source table.

Public repository contents are limited to project-authored analysis, task/rubric documentation, aggregate reference summaries, and a comparison figure. The source archive, raw clinical/spectral observations, participant-level prediction exports, private conversations, full model-response transcripts, and platform grading materials are not committed. Source data can be obtained from Dryad and verified locally. Earlier registry starter files with unresolved compilation provenance are not redistributed here.

The source provides processed terminal features, not the withheld continuous recordings, protected source surveys, or proprietary device loaders. The analysis makes no identity inference or claims of continuous measurement coverage.

An input-packaging revision removed author/application metadata from a background workbook and rephrased a task note. No clinical values were changed. That workbook is not used in the published replay; `verify_source.py` verifies the original source archive rather than a modified workbook package.

The 0.60 AUC gate, candidate specification, primary +10-hour alignment and technical qualification policy are project scenario assumptions. They are not attributed to the original investigators as clinical deployment standards. Sensitivity to +11 hours and a ±24-hour envelope is explicit.
